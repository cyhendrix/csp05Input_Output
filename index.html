How to use this lab

Work through all 10 parts in order. For each part: read the code, predict what will happen, run it in your online Python editor, then complete the Your Turn challenge.

Part 1 — print() Parameters

Goal: Practice multiple print() parameters.

name = "Jordan" score = 98 print("Player:", name) print("Score:", score)
Predict: Why is there a space between the label and the value?
Your Turn: Change the name and score. Then explain why print() places a space between separate parameters.
Player: Jordan Score: 98

Part 2 — sep and end

Goal: Control separators and line endings.

print("A","B","C",sep="-") print("Ready",end=" ") print("Set",end=" ") print("Go!")
Your Turn: Change sep to #. Then make 3 2 1 GO! appear on one line using separate print() statements.
A-B-C Ready Set Go!

Part 3 — User Input

Goal: Collect and use text input.

name = input("Enter your name: ") color = input("Enter your favorite color: ") print(name, "likes", color)
Your Turn: Add one more input question and include that answer in the final output.

Remember: input() returns a string.

Part 4 — Numeric Input

Goal: Convert input before doing math.

ageText = input("Enter your age: ") age = int(ageText) print("Next year you will be", age + 1)
Your Turn: Ask for a decimal height and convert it with float().
Think: What happens if the user types orange and the code tries int("orange")?

Part 5 — Basic str.format()

Goal: Insert a value into a placeholder.

name = input("Name: ") result = str.format("Hello, {}!", name) print(result)
Your Turn: Add a second placeholder for the user's favorite class.

Part 6 — Numbered Placeholders

Goal: Use zero-based placeholder indexes.

result = str.format("{1} {0}", "Hendrix", "Ms.") print(result)
Your Turn: Use three values and print them in reverse order with {2} {1} {0}.
Ms. Hendrix

Part 7 — Width and Alignment

Goal: Practice left, center, and right alignment.

print(str.format("|{0:^15}|", "Python")) print(str.format("|{0:<15}|", "Left")) print(str.format("|{0:>15}|", "Right"))
Your Turn: Change each field width from 15 to 20.

Part 8 — Truncation

Goal: Limit a string to a maximum number of characters.

artist = "Rumpelstiltskin" print(str.format("|{0:^20.10}|", artist))
Your Turn: Try a short name and a long name. Confirm that the long name is limited to 10 characters.

20 = field width • .10 = maximum 10 characters • ^ = center

Part 9 — Number Formatting

Goal: Format large numbers with commas.

price = 1500 print(str.format("Price: ${0:6,}", price))
Your Turn: Change price to 2500000 and observe the comma separators.
Price: $ 1,500
